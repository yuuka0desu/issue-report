# FunctionalStorage 问题反馈

本仓库只用于收集 **FunctionalStorage Paper/Folia 移植版** 的问题反馈与功能建议。

## 提交问题前

请先在 Issues 中搜索是否已有同类问题。

## 提交时请附上

1. 服务端核心与版本（Paper / Folia / Purpur，以及 MC 版本）
2. CraftEngine 版本
3. 插件版本（`/fs version` 输出）
4. 完整报错或日志片段（`logs/latest.log` 中 `FunctionalStorage` 相关的行）
5. 复现步骤：做了什么、期望什么、实际发生了什么
6. 涉及 GUI / 渲染的问题请附截图
